# _pendientes/

Projects that are not ready to publish: each one keeps its `.md` (moved out of
`_projects/`) and its images in a subfolder here, e.g.

    _pendientes/mi-proyecto/mi-proyecto.md
    _pendientes/mi-proyecto/img/...

This folder is excluded from the Jekyll build (`_config.yml`), so nothing here
gets a page. While it waits, the project is listed in `_data/proximamente.yml`
and shows as a "Bientôt / Coming soon" card.

WARNING: the GitHub repository is public. Everything in this folder (and
everything ever committed, in the git history) can be read on GitHub.
